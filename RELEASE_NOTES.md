Unofficial port of Create: Bells & Whistles 0.4.7 to Fabric Minecraft 26.2, built against Create Fly. Verified on a real 26.2 dedicated server.

- All 36 decorative blocks ported, with recipes, loot tables, and creative tab
- Recipes updated for 26.2 item and tag changes (copper nugget, glass blocks)
- Blocks keep their placement state across server restarts
- Ladder-style blocks remain climbable

Requires Fabric API and Create Fly 6.0.9-1 on Java 25. Client-side visuals are still in beta testing — please report rendering issues.
