# Create Fly: Bells & Whistles (Unofficial Port)

Decorative detailing for trains and stations: grab rails, bogie steps, door steps, headlights, pilots, platforms and the metro block set.

> [!IMPORTANT]
> **This is an unofficial port.** It is not affiliated with or endorsed by
> aesefficio. 
> Please report problems here.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.2` |
| Mod loader | Fabric Loader `0.19.3` or newer |
| Create Fly | `6.0.9-1` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Download

- [Modrinth](https://modrinth.com/project/uIZsYYiH)
- [GitHub releases](https://github.com/chaevsfe/BellsAndWhistlesMod/releases)


## Building

```
git clone https://github.com/chaevsfe/BellsAndWhistlesMod
cd createaddition
./gradlew build
```

Requires JDK 25.
